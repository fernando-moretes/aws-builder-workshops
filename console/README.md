Practice reviewing an AI agent on five adverse cases: missing data, stale evidence, an injected instruction in a runbook, an out-of-scope request. Pratique em português ou inglês.

**This is a teaching simulation.** Fictional data and a deterministic answer: it is not model output and observes no real system. Everything runs in your browser, with no server and no account. Paste an answer from any model to check its citations. A clean check does not make it right.

Independent project by [Fernando Azevedo](https://fernando.moretes.com), not official AWS material. [Source and docs](https://github.com/fernando-moretes/aws-builder-workshops).
