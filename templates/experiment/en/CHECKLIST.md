# Before publishing

## Authorship
- [ ] The text tells what **I** did and observed.
- [ ] AI only reviewed. I can explain every claim without it.
- [ ] If AI helped, the article says how.

## Evidence
- [ ] There are expected and observed results.
- [ ] Someone else can repeat it using only what is written.
- [ ] Numbers came from my test or have a source. None came from AI memory.
- [ ] The article says what the test does not prove.

## Sources
- [ ] Every decisive technical claim has a primary source.
- [ ] I opened each link and it says what I claim.
- [ ] I recorded the access date: services and prices change.

## Cost and cleanup
- [ ] I stated whether the exercise costs anything, and how to avoid the cost.
- [ ] There is a local alternative for people without a cloud account.
- [ ] I listed what to create and how to delete it. I checked that I deleted it.

## Security and data
- [ ] No keys, accounts, internal IPs or customer data in the text, images or code.
- [ ] Nothing I can't publish because of my job or a confidentiality agreement.
- [ ] I speak for myself, not for my employer.
