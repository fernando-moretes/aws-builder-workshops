# Exemplo completo: "30 consumidores resolvem meu backlog?"

Este é o resultado de seguir a trilha [Primeiro experimento](../../website/src/content/docs/trilhas/primeiro-experimento.mdx) do começo ao fim, em português. Use como referência, não como modelo a copiar: o seu experimento precisa partir de uma dúvida sua.

| Arquivo | O que mostra |
|---|---|
| [PROPOSTA.md](PROPOSTA.md) | Dúvida, público, hipótese e critério de evidência, escritos antes do teste |
| [EVIDENCIAS.md](EVIDENCIAS.md) | Comandos e saídas reais, inclusive a hipótese que caiu |
| [ARTIGO.md](ARTIGO.md) | O artigo escrito a partir da evidência |
| [CHECKLIST.md](CHECKLIST.md) | A checagem antes de publicar |

Para repetir, sem conta na nuvem: `npx -y moretes-builder-workshops queue --arrivals 100 --service-ms 200 --consumers 30 --backlog 6000`.

Os números são de um exercício com dados fictícios e taxas constantes. Não são um benchmark nem vêm de um sistema real.
