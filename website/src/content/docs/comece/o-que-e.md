Builder Workshops é um kit aberto para aprender e ensinar agentes de IA e arquitetura de sistemas fazendo, e não só lendo.

## O que tem aqui

| Peça | Para que serve | Precisa de quê |
|---|---|---|
| [Primeiro experimento](/aws-builder-workshops/trilhas/primeiro-experimento/) | Sair de uma dúvida real para um artigo técnico | Node.js ou Docker |
| [Lab de triagem](/aws-builder-workshops/trilhas/lab-triagem/) | Praticar a avaliação de um agente em 5 casos adversos | Só o navegador |
| [Capacidade de fila](/aws-builder-workshops/trilhas/capacidade-de-fila/) | Prever quando mais consumidores ajudam | Só o navegador |
| [MCP e skill](/aws-builder-workshops/agentes/mcp/) | Usar tudo isso de dentro do seu IDE ou agente | Node.js ou Docker |
| [Três workshops](/aws-builder-workshops/facilitar/os-tres-workshops/) | Conduzir encontros de 120 minutos | Papel já funciona |
| [Bedrock opcional](/aws-builder-workshops/trilhas/bedrock-opcional/) | Ver um modelo real nos mesmos casos | Conta AWS, pode ter custo |

## O que esperar, e o que não esperar

:::note[É]
Material de estudo independente, com dados fictícios e resultados reproduzíveis.
:::

:::caution[Não é]
Treinamento oficial da AWS, programação confirmada em evento, benchmark ou arquitetura pronta para produção. Veja os [limites conhecidos](/aws-builder-workshops/referencia/limites/).
:::
