Em 5 minutos, você vai quebrar uma função de propósito e usar a IA para entender o erro, sem conta na AWS. Precisa de Python e de um assistente de IA.

<Steps>

1. **Baixe a missão.**

   ```sh
   npx -y moretes-builder-workshops missao 3 minha-missao
   cd minha-missao
   ```

   Sem Node.js? Baixe os arquivos da [pasta da missão](https://github.com/fernando-moretes/aws-builder-workshops/tree/main/missoes/03-lambda-quebrada).

2. **Antes de rodar, aposte:** o que acontece se a função receber um evento vazio?

3. **Rode.**

   ```sh
   python3 rodar_local.py '{}'
   ```

   ```text
   KeyError: 'nome'
   ```

4. **Peça ajuda à IA, sem pedir a resposta pronta.**

   ```text
   Você é meu tutor. Estou aprendendo a ler erros e NÃO quero a correção pronta.
   Este é meu código: [cole o lambda_function.py]
   Este é o erro: KeyError: 'nome'
   Me diga em qual linha olhar e me faça uma pergunta para eu achar a causa.
   ```

5. **Responda à pergunta dela.** Pronto: você acabou de investigar um erro, em vez de só copiar a solução.

</Steps>
