## How we think

<div class="bw-grid">
  <div class="bw-card"><strong>Evidence before opinion</strong><span>Expected and observed, including what failed. We publish the model's real mistakes in the evaluation.</span></div>
  <div class="bw-card"><strong>Local first</strong><span>Everything starts with no account and no cost. The cloud comes in when it makes sense, with cost and cleanup explained.</span></div>
  <div class="bw-card"><strong>Read-only</strong><span>No tool changes anything. This limit is structural: the agent is never given the capability.</span></div>
  <div class="bw-card"><strong>Your authorship</strong><span>AI is the reviewer. What you publish is what you tested and can explain.</span></div>
