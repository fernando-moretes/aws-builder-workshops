Builder Workshops is an open kit for learning and teaching AI agents and systems architecture by doing, not just reading.

## What's here

| Piece | What it's for | What you need |
|---|---|---|
| [First experiment](/aws-builder-workshops/en/trilhas/primeiro-experimento/) | Go from a real question to a technical article | Node.js or Docker |
| [Triage lab](/aws-builder-workshops/en/trilhas/lab-triagem/) | Practice evaluating an agent on 5 adversarial cases | Just the browser |
| [Queue capacity](/aws-builder-workshops/en/trilhas/capacidade-de-fila/) | Predict when more consumers help | Just the browser |
| [MCP and skill](/aws-builder-workshops/en/agentes/mcp/) | Use all of this from inside your IDE or agent | Node.js or Docker |
| [Three workshops](/aws-builder-workshops/en/facilitar/os-tres-workshops/) | Run 120-minute sessions | Paper works fine |
| [Optional Bedrock](/aws-builder-workshops/en/trilhas/bedrock-opcional/) | See a real model on the same cases | AWS account, may cost money |

## What to expect, and what not to

:::note[It is]
Independent study material, with fictional data and reproducible results.
:::

:::caution[It is not]
Official AWS training, a session confirmed on an event agenda, a benchmark or a production-ready architecture. See the [known limits](/aws-builder-workshops/en/referencia/limites/).
:::
