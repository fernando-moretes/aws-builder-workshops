In 5 minutes, you will break a function on purpose and use the AI to understand the error, with no AWS account. You need Python and an AI assistant.

<Steps>

1. **Download the mission.**

   ```sh
   npx -y moretes-builder-workshops missao 3 my-mission --lang en
   cd my-mission
   ```

   No Node.js? Download the files from the [mission folder](https://github.com/fernando-moretes/aws-builder-workshops/tree/main/missoes/03-lambda-quebrada).

2. **Before you run it, place a bet:** what happens if the function receives an empty event?

3. **Run it.**

   ```sh
   python3 rodar_local.py '{}'
   ```

   ```text
   KeyError: 'nome'
   ```

4. **Ask the AI for help, without asking for the ready-made answer.**

   ```text
   You are my tutor. I am learning to read errors and I do NOT want the ready-made fix.
   This is my code: [paste lambda_function.py]
   This is the error: KeyError: 'nome'
   Tell me which line to look at and ask me a question so I can find the cause.
   ```

5. **Answer its question.** Done: you just investigated an error instead of only copying the solution.

</Steps>
