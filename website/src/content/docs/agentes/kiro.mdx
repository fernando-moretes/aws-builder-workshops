<Steps>

1. **Instale na pasta do seu projeto.**

   ```sh
   npx -y moretes-builder-workshops init kiro
   ```

   ```text
   ✓ .kiro/settings/mcp.json
   ✓ .kiro/skills/builder-workshops
   ✓ .kiro/steering/builder-workshops.md
   ```

   Servidores que já estejam no `mcp.json` são preservados.

2. **Confira o servidor.** Abra o painel de MCP do Kiro e veja se `builder-workshops` aparece conectado, com 10 ferramentas.

3. **Faça o primeiro pedido.**

   > Use builder-workshops. Me guie na missão 3, um passo por vez, e me pergunte minha hipótese antes de explicar.

4. **Comece seu experimento.**

   > Quero começar meu primeiro experimento com a skill builder-workshops. Não escreva por mim.

</Steps>

## O que cada arquivo faz

| Arquivo | Papel |
|---|---|
| `.kiro/settings/mcp.json` | Registra o servidor. Vale para este workspace |
| `.kiro/skills/builder-workshops/` | A skill, carregada quando o pedido combina com ela |
| `.kiro/steering/builder-workshops.md` | Regras do projeto, com inclusão manual: chame no chat com `#builder-workshops` |

Quer em todos os projetos? Copie a skill para `~/.kiro/skills/` e o servidor para `~/.kiro/settings/mcp.json`. O mesmo `mcp.json` serve no Kiro CLI.

## Dentro deste repositório

O repo já vem configurado: abra a pasta no Kiro e o servidor roda a partir do código local.

:::caution[Ainda não testado em um Kiro real]
Os caminhos seguem a [documentação do Kiro](https://kiro.dev/docs/mcp/configuration/) e o servidor é testado com o cliente oficial do MCP, mas nenhum teste foi feito dentro do próprio Kiro até agora. Se você testar, [conte como foi na issue #1](https://github.com/fernando-moretes/aws-builder-workshops/issues/new?template=reproducao.yml).
:::
